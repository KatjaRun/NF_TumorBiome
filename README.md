# NF_TumorBiome
Pipeline is still under development.

## Introduction
NF_TumorBiome is a nextflow pipeline that can be used to analyze metatranscriptomics, metagenomics, and amplicon sequencing data. It analyzes the composition of the intratumoral microbiome and can be used for hypothesis generation for possible relationships between microbes and antitumor immunity or patient survival.
